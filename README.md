# Grace Karen Homes

Private brokerage site for Grace Karen Homes, built with Next.js. The catalogue, phone numbers, and client notes are sample launch content. Replace them in `src/lib/data.ts` and `src/lib/site.ts` before you treat the site as live inventory.

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The Ghana map is at `/map`.
